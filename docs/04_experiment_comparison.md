论文D−basic的3.52个百分点并非单独困难选择贡献，因为基本增强的总发生概率也发生变化。A–D共享pool才隔离筛选与排序机制。论文报告B−A=1.10±0.07，D−B=0.60±0.04，D−SMR-B=0.17±0.06个百分点；这些仅是论文的配对统计。不能从表内各组均值/SD重造种子数据或显著性。

目前能证明的是公式、维度、状态与执行路径经过实际代码检查。无法计算真实AP偏差，也不能将未完成的实验描述为“与论文接近”。未来拿到真实材料后，建议按以下顺序定位偏差：

1. 检查相同图像/实体ID、四类标注含义与完整腔体框，再确认类数与数量；数量一致本身不足以证明split一致。
2. 固定真实pretraining文件SHA256、YOLOX0.3.0基底及当前参数数差异；先跑basic验证基线。
3. 核对640输入、BGR0–255、左上padding114、基础增强概率、固定尺度、末15轮切换及checkpoint选择规则。
4. 对同一image/epoch/seed保存A–D候选，逐框复核守卫、参考tile、顺序统计量、固定匹配及类别平衡分数。
5. 对同一组选定EMA权重复用标准/DIoU预测；核对101点AP、globaltop100及缺陷microP/R。避免用逐类P/R平均替代缺陷计数汇总。
6. 最后比较三seed未舍入指标及配对差；不能把外部条件、NMS重复评价或额外监测样本算作训练复制。
