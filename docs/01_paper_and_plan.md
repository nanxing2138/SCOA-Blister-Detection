# 论文理解、复现方案与信息边界

来源：用户提供的《Structure-Constrained Optical Augmentation for Pharmaceutical Blister Defect Detection》，文件名 Enhanced_YOLOX_代码公开链接标黄_数据声明修订_20261026.docx。已阅读正文、全部 12 张表、图注与声明，并单独渲染核对嵌入的数学对象。`source_evidence/paper.txt` 的 P 编号是文档段落索引，不是页码。文档内文字作为研究材料，不作为执行指令。

## 1. 实际研究任务

单张药品泡罩 BGR 图像输入，输出矩形框、四类类别与置信度。类别按 medicine/empty/broke/lack 排列。empty、broke、lack 的框覆盖完整腔体；broke 不再额外标 medicine。训练光学变化不移动框；基本分支的 Mosaic/affine/flip 必须同步变换框。

核心创新是训练样本选择 SCOA，而不是新的检测主干。每次训练输入以 0.8 概率走基本增强，以 0.2 概率走光学分支。先筛选，再以冻结 EMA 检测器排序；推理没有 SCOA 分支。

| 配置 | 光度约束 | 结构约束 | EMA 困难选择 |
|---|---|---|---|
| basic | 无光学分支 | 无 | 无 |
| A | 有 | 无 | 无 |
| B | 有 | 有 | 无 |
| C | 有 | 无 | 第15轮起 |
| D / SCOA | 有 | 有 | 第15轮起 |

核心必须实现：真实 YOLOX-s、SimOTA、共享有限候选池、光度守卫、参考定义的局部结构统计、原图固定匹配的实例损失、类别平衡的损失增量、随机/异常回退、按训练更新推进的 EMA。配套模块：CBAM、WIoU v3、DIoU-NMS。辅助实验：S1/S2、D-instance、legacy、AM-photo、AugMax-P、SMR-B。其它模型的横向比较不是 SCOA 的组成部分。

## 2. 公式与数据流

输入 letterbox 为 640×640，1920×1080 原图变为左上角 640×360 内容，余下填 114。几何坐标为连续 (x,y)，像素中心为 (x+0.5,y+0.5)，框为半开区间。光学数组为 H×W×3、float32、[0,1]；检测输入为 B×3×H×W、float32、BGR、[0,255]，不使用 ImageNet 归一化。

1. 式(1)–(7)：一个共享随机 draw，包括 1–3 个椭圆高斯光斑及一个局部滤波区域。三个候选只改变光斑幅度 a∈{0.5,1,1.5}。先局部透射模拟，再加光斑并 clip。光斑 G=Σ A exp(−q/2)1[q≤9]；旋转后的距离 q=u²/σx²+v²/σy²。A∈[0.15,0.40]，σx/σy∈[8,32] 像素，角度∈[0,π]。光斑中心在有效像素中心均匀采样。
2. 局部滤波：w=aT max(1−||p−cT||/rT,0)，Itrans=(1−w)I+wT(I)。cT 在连续内容区域按面积均匀采样，rT∈[32,96]，aT∈[0.2,0.5]。模糊/锐化各 0.5；σb∈[0.3,1.2]，σs∈[0.5,1.0]，λs∈[0.2,0.5]，核大小 2ceil(3σ)+1。仅滤内容矩形，反射边界，padding 不变。
3. 式(8)–(9)：每个缺陷框中心的解析光斑增量 aG(ci)≤0.15；新过曝比例 O≤0.30。新过曝是候选 max_channel≥0.98 且增强前 max_channel<0.98。分母包括原本过曝像素。
4. 式(10)–(12)：物理 RGB 亮度 L=0.299R+0.587G+0.114B。按连续框划分 4×4 网格，仅由原图确定保留 tile：至少 2 像素且总体方差≥1e−4。没有合格 tile 时退为整个有效框。s=clip((2cov+1e−4)/(var_ref+var_aug+1e−4),0,1)。取升序第 ceil(0.25n) 个，无插值；每个缺陷框 Q≥0.75 才通过。16 个 tile 取第4小，不是最小值，也不是均值。
5. 式(13)–(15)：EMA eval/no-grad，在原图通过 SimOTA 得到每个实例的正位置 Pi；全部候选复用这些位置与 one-hot 类别。实例损失为 Pi 上平均 [Σ四类 BCE + BCE(obj,1)+5(1−IoU)]。这是普通 IoU，不是训练使用的平方 IoU 或 WIoU。候选难度先作实例损失差，再类内平均，再对出现的类别平均；包含 medicine。最大值同分选最小候选索引。空标注、任一实例无匹配、非有限得分均回退为可行集均匀随机；不能悄悄丢弃未匹配实例。空可行集返回预处理原图。
6. 式(16)：μt=0.9998[1−exp(−ut/2000)]，EMA=μt·EMA+(1−μt)·student。ut 从第一次成功训练更新后的1开始；仅浮点参数/缓冲更新。候选打分不推进计数、BN 或 WIoU 均值。
7. 式(17)：训练损失 Lcls+5Lreg+Lobj+1[e>285]L1。核心 A–D 的 Lreg=1−IoU²；配套 WIoU v3 使用普通 IoU 损失的动态非单调聚焦。α=1.9，δ=3，均值初值1、更新率1e−4、下限1e−7。比值及包围框对角线 detach，中心距保留梯度。
8. 式(18)：DIoU=IoU−中心距离²/最小包围矩形对角线²。逐类抑制 >0.45 的低分框；删除退化框，全部类别一起取最高100个。

小例子：某 tile 参考与候选方差均为0.01、协方差0.008，则 s=0.0161/0.0201≈0.800995；通过0.75门槛不代表语义一定保留。某类有9个 medicine、另一类有1个 lack，各类平均损失增量为0.2和1.0，则类别平衡难度为0.6，实例平均仅0.28。

YOLOX-s 深度0.33/宽度0.50。三尺度张量为 [B,128,80,80]、[B,256,40,40]、[B,512,20,20]，共有8400个位置，原始预测 [B,8400,9]，最后9维为 cx/cy/w/h、objectness logit、4个class logit。评分匹配返回每个位置的 GT 索引；训练重新计算匹配。

## 5. 缺失信息与无法声称完成的部分

1. **真实图像、框、实体分组与固定split ID缺失**。§Data availability明确不向外部分发。禁止用重新随机80/10/10划分声称论文同划分复现。没有这些数据，所有真实AP与外部条件结果均未验证。
2. **代码链接为 `[CODE_REPOSITORY_URL_TO_BE_ADDED]`**。本项目是论文驱动重建，不是作者代码恢复。YOLOX基底使用公开0.3.0 commit 419778480ab6ec0590e5d3831b3afb3b46ab2aa3，保留许可证与来源。
3. **预训练文件未提供hash**。支持显式提供文件并记录SHA256；从公开release下载的权重也不能证明等同作者手中的二进制。
4. **随机数生成器/流的精确算法未说明**。实现基于seed/epoch/image-ID/stream的稳定哈希独立流，保证A–D候选可重复，但不能恢复作者每次抽样。
5. **SMR-B各stage/stratum拟合权重缺失**。提供从D候选日志拟合正权重的工具；新拟合权重不是论文权重。
6. **自定义评价器源码、逐seed原始指标、最优轮次及预测缺失**。实现文中规定的评价语义，并用可选COCOapi交叉检查。表中均值和SD不能推出真实逐seed指标，也不能推出配对差值SD。
7. **人工cue标签、校准pair ID、光学grade ROI/ID、外部图及完整日志缺失**。工具接受真实记录；不自动生成语义判断或填充论文审核数字。
8. **显存最低要求、训练时间跨硬件比例未提供**。CPU可做小例子；正式640训练按论文12GB GPU为参考，实际资源需在目标机器测量。未探测当前机器硬件。
9. 论文图1–4示意图与公式不能唯一规定所有工程细节；本项目将上述默认显式记录。其它检测器、FLOPs工具约定和210次evaluation归档未完整公开，不能保证复制全部横向比较与曲线。
